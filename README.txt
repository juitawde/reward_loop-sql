RewardLoop — Beginner-friendly SQL project

Database: PostgreSQL 14+
Run in order:
1. 01_rewardloop_schema.sql
2. 02_rewardloop_sample_data.sql
3. Run queries in 03_rewardloop_queries.sql one at a time
4. 04_rewardloop_redemption_transaction.sql
5. Render 05_rewardloop_er_diagram.mmd in a Mermaid editor

The scripts use basic SQL concepts and avoid COALESCE, identity columns, and indexes.
